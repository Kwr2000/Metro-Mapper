# Metro Mapper

A map-first explorer for the Austin metro housing market and neighborhoods: compare small
named areas on schools, safety, walkability, flood risk and demographics, and check a home
you found on a listing site against public appraisal data.

**Status:** Phase 0 (source discovery and verification). No site yet. See
[`docs/STATUS.md`](docs/STATUS.md) and [`docs/PLAN.md`](docs/PLAN.md).

Every number on the site will show its source and as-of date. Texas does not disclose home
sale prices, so home values here are **appraisal-based value ranges**, not market prices.
Data sources and their terms are listed in [`docs/SOURCES.md`](docs/SOURCES.md).
